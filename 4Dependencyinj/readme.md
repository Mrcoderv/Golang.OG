// Dependency Injection means: instead of a function/struct creating the thing it needs, we provide that thing from outside.

in my language:= Dependency Injection means distributing responsibilities into separate components. For example, we can create a separate dependency for database operations and another for authentication, then connect them to the main system. This helps keep the code organized, reusable, and easier to maintain. Instead of creating everything from scratch for small tasks, we can provide and reuse the required components.
